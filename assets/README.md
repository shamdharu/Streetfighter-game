# Assets

This game uses **no external asset files**:

- All characters, scenery, items and animations are drawn procedurally with HTML5 Canvas (`js/stickman.js`, `js/level.js`).
- All sound effects are generated at runtime with the Web Audio API (`js/audio.js`) — no sampled or copyrighted audio.

Keeping assets generated means the game has zero downloads, loads instantly, and cannot contain third-party IP.
